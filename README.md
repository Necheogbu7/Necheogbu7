## ☁️ Cloud & Security Projects

### 🌐 [Hybrid Windows Server 2025 & Entra ID Lab](https://github.com/Necheogbu7/2025serverLab)

A full hybrid enterprise environment joining on-premises Active Directory to Microsoft Entra ID — the complete identity lifecycle from domain build to cloud sign-in.

- Deployed **Windows Server 2025** as a domain controller for the `crop.Lanitc` domain
- Designed OU structure (Finance / HR / Users) with matching security groups
- Built an RBAC file server with NTFS permissions, and **verified cross-department access was denied**
- Automated departmental drive mapping via **GPO** with item-level targeting
- Synced 8 users to Entra ID through **Entra Connect** with Password Hash Sync + Seamless SSO

`Windows Server 2025` `Active Directory` `Entra Connect` `Group Policy` `RBAC` `Hybrid Identity`

---

### 🚀 [Microsoft Intune, IAM & Endpoint Security Lab](https://github.com/Necheogbu7/Intune)

Cloud-native device and identity management for a modern, unmanaged-endpoint workforce.

- Enrolled and managed Windows 10 endpoints through **Microsoft Intune**
- Provisioned IAM test users and handled licensing via the **M365 Admin Center**
- Applied compliance and configuration policies to enforce endpoint security baselines

`Microsoft Intune` `Entra ID` `Endpoint Manager` `M365` `Compliance Policy`

---

### 🛡️ [Azure Sentinel SIEM — Failed RDP Geolocation Map](https://github.com/Necheogbu7/sentinalproject)

Exposed a deliberately vulnerable VM to the internet as a honeypot, then tracked live brute-force attacks on a world map.

- Stood up **Azure Sentinel (SIEM)** against a live, intentionally exposed VM
- Wrote a **PowerShell** parser for failed-RDP events in Windows Event Log
- Enriched attacker IPs with geolocation data via the ipgeolocation.io API
- Queried custom logs in **KQL** and plotted real attacks worldwide on a Sentinel workbook map

`Azure Sentinel` `KQL` `PowerShell` `Log Analytics` `Threat Detection`
